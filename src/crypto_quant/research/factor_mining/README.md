# FM-v6 因子挖掘

本模块将研究问题和逐小时市场数据变成可追溯的因子创意卡。当前执行入口只支持 FM-v6 合同、SQLite 数值证据和引用式 Goal 记录。

```text
研究问题与 A 数据 → 构想 → 计算与修复 → 评估解释 → 优化决定
                                      ↑               │
                                      └── 修改任务 ───┘
保留候选 → 冻结公式、方向、A 证据与 B 币池 → 一次 B 验证 → 解释与创意卡
```

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `contracts.py` | 当前研究合同、候选定义及模型输出的业务校验 |
| `agent_ideator.py` | 根据研究问题或修改任务生成公式 |
| `landscape.py` | 用 A 段候选构建信号相关性的层次树、覆盖与分支证据 |
| `agent_calculator.py` | 执行公式、处理计算错误、保存因子值 |
| `agent_evaluator.py` | 解释程序证据，标明已读取的范围 |
| `agent_optimizer.py` | 决定 retain、optimize、pause、discard，提供下一轮修改任务 |
| `evaluation.py` | 标签、横截面分组、HAC 检验、配对比较和 BH 校正 |
| `workflow.py` | A 循环、冻结、B 验证、补报告和卡片交付 |
| `goal.py` | 任务选择、等待、恢复、数量或质量成果核验 |
| `records.py` | 运行记录、证据读取、模型上下文与请求留档 |
| `factor_archive.py` | 按因子身份保存 SQLite 评估和因子值 |
| `reporting.py` | 根据保存的证据生成报告和图表 |
| `model.py`、`model_config.py`、`mimo_model.py`、`codex_model.py` | 模型协议、设置及接口实现 |
| `runtime.py`、`structured_output.py` | 角色调用与回复结构校验 |
| `cli.py` | 命令行入口与数据加载 |

公式超过节点、文本复杂度或历史长度预算时，保留原式并记录计算失败，不调用模型删项、删除归一化分母或缩短窗口来绕过限制。一般语法/算子错误仍走既有修复流程，修复须保留计算含义。

## 唯一研究口径

合同显式声明 `fdr_method="BH"`、`b_horizons=[1, 4, 24]`、`admission_scheme="plan3"`、`plan3_tracks_gate=false`。B 可送检期限固定为 1h、4h、24h，不开放任意期限配置。后两个字段保留当前 V6 保存合同的格式，仅描述固定的标签规则，不再选择旧版算法。

A 段多期限评估使用共同有效样本；Optimizer 依据完整 A 证据为每个 `retain` 候选明确输出非空 `retained_horizons`。冻结后，B 只验证这些已保留期限。每个候选 × 期限贡献一个双侧 Rank IC 检验，所有冻结检验统一进行 BH 校正；无法估计的检验仍在家族中，校正时按 p=1 处理。该候选只有在 A 保留期限与 B 通过期限有交集时才能入池。

每个送检期限都要求 BH 校正通过、固定方向 IC 达到合同 `min_abs_ic`、有向平均价差大于零。三轨、阶段同向率和 ICIR 保留为诊断。研究合同示例在 2026-10-02 全部 44 个 A 候选标定后采用统一 IC 下限 0.01；决策和历史规则影响见 [IC 门槛调整 Plan](../../../../docs/plans/FM-v6_IC门槛调整Plan.md)及保留在 e535 的 [标定证据](/Users/stellan/.codex/worktrees/e535/量化投资/experiments/factor_mining/ic_calibration_20261002/)。旧冻结运行仍使用各自合同中的 0.02。工程样例为 0.01，工程用途不能入池。`min_directional_spread` 和 `min_stage_share` 保留在 V6 合同中以维持已有证据身份，不再参与准入分支。

公式校验限制白名单、参数、复杂度、回看、有限数值和时间边界；不做单位推导或文字语义准入。优化角色只提供修改任务，下一轮具体公式由构想角色生成。模型附加字段留档后排除，模型意见不能覆盖 B 程序判定。

## 信号持续性与受控修改

新运行在 A、B 各为每个候选计算一次 `rank_displacement`，分别保留 1h、4h、24h 间隔 Δ。对 t 和 t−Δ 两端均合格且因子值有限的共同币种，分别计算平均名次的百分位 `q=(rank−0.5)/n`，逐时变化为 `D=mean(abs(q_t−q_previous))`。各有效时点等权汇总；保留完整小时网格、段边界排除、两端及共同覆盖、并列情况和阶段摘要。Δ 是观测间隔，与预测期限 H 分开记录。诊断不依赖收益标签，也不把缺失当作零变化。

`rank_displacement` 修改实验必须在生成公式前指定 `horizon_hours`、`displacement_hours`（各取 1、4、24）、D 绝对改善下限 `min_improvement` 和允许的方向 IC 损失 `max_ic_loss`。程序使用新旧版本两端以及 H 标签均有效的共同币种重算排名与 IC，在相同有效时点比较 `D_control−D_trial` 和冻结方向下的 `IC_trial−IC_control`，沿用 HAC 与路线状态判定。只有两个区间下界均满足预声明条件才继续；上界已无法满足条件时停止；其余暂停。独立诊断与配对证据分别保存。单版 A 的多期限比较使用共同 24h 标签边界、末端剔除 25h；rank_displacement 配对使用预声明 H 自身的下一开盘标签边界、末端剔除 H+1h，并要求 D 两端在 A 内。配对没有自定义末端掩码接口，任务或 proposal 文字不得将单版的 25h 剔除搬入 1h/4h 配对。

Evaluator 解释预测能力、D、覆盖和阶段差异；Optimizer 可据此提出修改任务，Ideator 再生成公式。排名稳定不能单独支持 retain，排名变化高也不是淘汰条件。该指标描述换手倾向，不计算成交费用或净收益；没有统一 λ、自动平滑或新的 B 入池门槛。B 的 D 仅作冻结定义下的描述诊断，不加入 BH 检验家族，不回流到 A 研究选择。设计与固定历史实验范围见[实施 Plan](../../../../docs/plans/FM-v6信号持续性与换手倾向前置Plan_20261003.md)。

## HAC 因子研究上下文

每次新的构想请求前，程序从本轮之前的 A 候选，以及 Goal 已提供的 `prior_A_research` 中收集研究历史，生成并保存当轮因子图谱。失败、未完成和暂停的研究仍保留在库存中。图谱不扫描正式创意卡池，不按 B 通过状态选择成员，也不读取 B/C 指标；单独新建的运行没有历史输入时，首轮图谱为空。

已执行的表达式在当前允许的 A 面板上重算，使用同一显式币池和合同采样间隔。距离为 `1 - abs(mean(cross_sectional_Pearson_r))`，对各有效采样时点等权求均值，再做 average-linkage 层次聚类。预热只用于公式计算，不进入相关性样本。每对因子至少需要 `max(3, min_symbols)` 个共同有效币种，且有效时点达到合同 `min_periods`。历史 A 的 IC、价差和 D 保留各自来源，不表示它们已在当前面板重新评估。

快照保留完整树、合并距离、代表公式、成员与字段覆盖及研究证据。图谱将完全相同的已执行展开表达式折叠为一个数值信号，保留各来源的预测方向与研究证据；这不改变候选身份或执行去重规则。不同时间窗口不会因为同属一个 AST 家族就被删除。常量、覆盖不足和无法在当前回看范围计算的候选明确标注，不当作低相关信号。其余候选若仍存在无法估计的相关对，则保存成对统计及原因，明确本轮没有完整树，不填补距离。

图谱只为构想提供软引导。拥挤分支允许有依据的改进；树不自动命名经济机制，也不能单凭成员数量证明某个方向存在机会。Ideator 在 `analysis` 和 `change_reason` 中解释与已有研究的差异、待验证的补充价值及依据。原有 pending 修改任务、固定方向和配对合同继续生效，跨分支公式组合的相关性仍需实际计算。

构想请求引用当轮快照，旧快照留档供回查；容量不足时通过现有证据读取机制分页，不固定截取前若干个因子。恢复未完成请求时复用已保存的快照，不把后来产生的候选混入该轮。这里的 HAC 是层次聚类，与评估均值及配对检验使用的 HAC 标准误分别处理。

## 数据边界

输入为 UTC 整小时 `(timestamp, symbol)` 面板、显式布尔币池和来源诊断。小时 t 的输入在 t+1h−1ms 可用，期限 H 的收益为 `perp_open[t+1h+H] / perp_open[t+1h] - 1`。预热不计入样本，标签终点达到下一段即排除。A 展示共同有效样本下的全部期限对照；B 按各自期限边界展示所有冻结期限、有效样本、排除数量和统计结果。币池、字段缺失和来源可用时间由输入模块校验。

因子入口仅读取 A/B。正式日期与数据既往使用说明由共享数据政策核验；当前数据包含事后插值，既有 B 曾参与规则选择。当前产物是研究线索，完整策略验证状态为 `not_started`。

## 冻结与恢复

A 只有明确 retain、已完成计算及解释的候选可以冻结。retain 决定同时保存 `retained_horizons` 及其 A 数值依据。冻结固定合同、公式、方向、保留期限、A 评估 ID、解释、决定和完整 B 成员资格。冻结后不能回到 A 修改证据或扩大 B 期限范围。

B loader 调用前先写访问标记。只有保存完整数值检查点才能补解释；中断不能自动重读 B。重复补报告复用数值与解释，已有卡片必须与保存证据一致。每个候选最多生成一张卡，卡片保存 A 保留期限、B 通过期限、逐期限程序判定、统计摘要及 SQLite 归档定位。Goal 交付证据另行保存期限判定和归档引用；目标匹配上下文只接收 A 定义与证据。身份、合同、成员资格和记录内容直接比较；哈希元数据不成为读取或恢复门槛。

Goal 用引用式 cycle 记录和保存的上下文索引读取 A 历史。已归档 cycle 直接复用；旧 cycle 缺少多期限摘要时，只在读取上下文时从原 A evaluation 补齐，不改写归档。选题器与构想器均收到质量目标的预测期限 H、排名变化间隔 Δ，以及逐期限 `horizon_hours`/`label`。成果核验使用独立上下文，只拿程序准入凭据及 A 证据；B 数值和失败原因不回流到研究任务选择。只有实际写卡、程序准入和目标匹配齐备才计入成果。数量目标按 `target_ideas` 完成；质量目标按预声明的 `quality_target` 核对 A 段排名变化配对改善与方向 IC 损失区间，并要求同一预测期限通过 B 准入。模型内容核验不能替代程序质量判定。质量目标的 `max_cycles` 省略或为 `null` 时持续到达标；可选的正整数上限用尽后以 `budget_exhausted` 结束且不标记完成。追加 Goal 状态的 `max_cycles` 覆盖原预算，取消上限后可从已结束的预算终态接续下一轮，保留原合同及已完成检查点。选题阶段通过 `read_records` 读取历史 A 原文，纯归档审查不下发为 `explore_new`；该动作必须允许并预期生成候选。若缺少执行配置、逐期掩码等审查证据且无法推进其他独立方向，选题器返回 `review_required`，列明缺失证据、核验问题和解除条件，程序直接进入 `blocked`（`research_review_required`），不创建 run 或增加 cycle。字段观测不足仍走原有 `wait_data`。连续两个已完成 A cycle 均未生成候选时进入 `blocked`，状态错误信息列出相关 cycle、任务和 A 完成记录；普通 `goal-resume` 会原样返回，不会重复启动。人工检查并处理原因后，可调用 `GoalRunner.resume_blocked_after_review()` 追加恢复状态，再使用 `goal-resume`；因连续空轮而阻塞时，已审查的空轮不计入恢复后的连续空轮阈值；审查证据阻塞的恢复不清零已有空轮历史。目标完成、预算用尽、等待、暂停、错误和阻塞有独立事件，运行锁禁止同一 Goal 并发执行。

## 记录与模型

运行目录保存合同、候选过程、冻结、模型调用、报告和状态；SQLite 保存数值证据。归档位置来自运行 marker 的相对路径，与加载代码的位置无关。新运行默认使用输出根目录下的 `factor_archive_v2/`。详见[因子证据归档](../../../../docs/guides/因子证据归档.md)。

A 的研究上下文保留全部研究记录；长数值表提供受控原文分页，不以最近若干条或固定字符数截断。模型回复和纠正请求留档，错误按现有任务边界处理。证据读取的 offset/limit 只分页数组，对象即使 limit=1 仍会完整返回；超预算读取在加入上下文前拒绝，并返回可继续读取的具体字段路径。单模型和四角色独立 Codex 模型均可通过入口显式选择；`--role-models` 配置必须包括 ideator、calculator、evaluator、optimizer，每项指定模型及推理强度。纠正和分页请求保留原角色，Goal 恢复逐项核验已保存的模型和运行时设置。模型选择与环境配置见[项目说明](../../../../README.md)；质量目标及角色配置见[操作说明](../../../../docs/guides/因子挖掘Agent使用说明.md#goal-模式)。

历史迁移、compact、Plan3 重跑和旧 Goal 重新优化工具已退出源码与默认测试。旧运行数据可在本地查看，当前执行入口不负责 V1–V5 的恢复或转换。

使用入口见[操作说明](../../../../docs/guides/因子挖掘Agent使用说明.md)。测试覆盖当前合同、因果时间边界、BH、角色分工、冻结、一次 B 访问、恢复及卡片幂等。
