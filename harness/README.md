# Factor Research DSH

本地研究 bundle 位于 `factor-research/`，固定适配 DSH `0.2.1-rc.2`。用户从研究协调输入，A/B 为持续、可打开的只读会话。领域计算由固定角色 MCP 完成；模型循环、持久 Session、Goal、事件与压缩使用 DSH 原生能力。

安装、配置层核对、启动、停止/恢复与合同变更见[本地安装与操作](../docs/guides/因子挖掘DSH本地安装与操作.md)。交付通过官方 `dsh plugin --profile factor-research add <本地 tgz>` 安装到项目专用 Harness home；不依赖 Codex SDK、个人全局配置或源码链接。

[工程报告](../docs/reports/DSH本地工程交付与验收_20261018.md)区分已通过、失败与待复验项目。真实行情、效果对比、推送、发布与部署不在本轮范围。
