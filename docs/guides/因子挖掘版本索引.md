# 因子挖掘程序版本索引

更新：2026-09-28。**当前程序主版本记为 FM-v6。** 我之前写的“A-03”只给 A 段流程编号，不能代表整个程序；这里停用该局部编号。

版本号用于讨论程序的主要演进阶段，不是代码中的配置字段，也不修改旧合同、Goal、运行目录或统计结果。同一主版本内仍有提示词、模型接入和故障修复的变化。复盘某一次运行，应以它保存的合同、模型调用及数值结果为准。

## 程序主版本

| 程序版本 | 首次阶段 | 整体能力与研究规则 | 代表记录 |
| --- | --- | --- | --- |
| **FM-v1** | 2026-09-14，四 Agent 工程版 | 构想→计算→评估→优化；程序执行受限公式和 A/B 统计。早期 B 对 Rank IC 与有向价差两类检验做 BY 校正。 | [工程联调](../../experiments/factor_mining/engineering_local_20260914_final/) |

| **FM-v3** | 2026-09-17，Goal 版 | 增加跨批任务选择、事件记录、等待与恢复；随后接入多年 30 币数据。主线 B 仍为旧 BY 双检验。 | [Goal 系列](../../experiments/factor_mining/goals/)、[多年数据](../../experiments/factor_mining/long_history_20260919_setup/README.md) |
| **FM-v4** | 2026-09-27，Plan3 研究版 | B 改为 BH 仅校正 Rank IC，保留有向 IC 门槛；价差与阶段同向率必须命中赔率、胜率或均衡三轨之一。A 仍由 Goal 和四 Agent 推进。 | [方案二／三并行记录](../../experiments/factor_mining/plan2_plan3_live_20260927/README.md) |
| **FM-v5** | 2026-09-28，量纲方案修订版 | 允许带单位中间计算，最终因子仍须跨币可比；A 段把 ICIR 作为诊断，不设 0.3 硬门槛；B 的 Plan3 三轨只打标签。该量纲方案未用于新的正式 Goal。 | [改造计划](../plans/因子挖掘Agent改造Plan.md) |
| **FM-v6** | 2026-09-28，当前代码 | 因子公式不做单位推导或跨币尺度准入；保留语法、参数、数值和时间边界。B 继续要求 BH Rank IC、合同 IC 下限及正的有向平均价差，Plan3 三轨只打标签。策略研究的共享表达式也不再强制无量纲。 | [新合同工程示例](../../examples/factor_mining/contract.example.json)、[模块说明](../../src/crypto_quant/research/factor_mining/README.md) |

FM-v6 的新合同不再有 `expression_policy`，仍可显式设置 `plan3_tracks_gate=false`。工程示例的 IC 下限为 0.010；尚无按 FM-v6 完成的正式研究 Goal 或新的独立 B 验证。此前的 `dimensionless_v1` 与 `comparable_v1` 量纲方案均不作为当前执行口径；旧运行证据不自动改写。
