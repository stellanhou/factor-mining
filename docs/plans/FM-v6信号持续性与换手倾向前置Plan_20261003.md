# FM-v6 信号持续性与换手倾向前置 Plan

日期：2026-10-03。实施进度（2026-10-04）：首版工程、E0 至 E4 固定历史研究及独立数值复核已完成；576 个候选完成画像，24 个父因子的 63 个可执行平滑变体完成对照，6 个固定公式完成来源审查。完整结论、验证和复跑入口见[实施验收报告](../../experiments/factor_rank_displacement/20261003/README.md)。下文保留事前设计、约 7 小时预算和后续研究清单；F1 至 F8 未纳入本次实施。

本计划为单因子挖掘增加信号持续性与换手倾向证据，使系统能够比较预测能力和信号变化之间的取舍。单因子继续为后续多因子组合提供候选；首版不定义单因子持仓，不计算单因子净利润，也不以独立盈利作为保留条件。

首版采用两个并列目标：保留现有预测评价，新增百分位排名变化指标，并将其接入 A 段的受控修改与配对检验。暂不合成 `IC − λ × 换手倾向` 总分，不指定统一 λ，不新增 B 入池门槛。

## 已确认的方向与本计划的设计选择

讨论已确认：成本相关反馈优先改；通过信号变化代理反映潜在换手；保留多因子组合的持仓自由；先观察预测能力与稳定性的取舍，再研究惩罚系数。

以下指标计算、配对样本和工程步骤为本计划提出的具体设计，实施时以这些可检查的定义为依据。首版没有证明代理指标能降低组合成交成本，后续需要单独验证这一关系。

本次不包含交易规则、费率设置、回测账户、相关性拦截、类别配额、残差标签、48h 或 72h 标签，以及跨周期去重策略修改。不会因实施本计划自动恢复已暂停的挖掘 Goal。

## 当前系统与改动位置

当前 FM-v6 已有 1h、4h、24h 预测评价；A 段使用共同样本比较期限，Optimizer 决定送 B 的期限，冻结后由程序执行 B 检验。B 准入依据为 BH 校正、合同中的方向 IC 下限及正有向平均价差。

当前修改实验的主指标只支持 `rank_ic` 和 `directional_spread`，程序按配对改善与允许 IC 损失决定路线继续、停止或证据不足。新增能力沿用这条链路。

## 排名变化指标

### 计算对象

对因子值计算间隔 Δ 为 1h、4h、24h 的排名变化。Δ 表示两次观测之间的时间距离，不表示预测期限、实际调仓周期或持有期；三种 Δ 都保留，不取其中最有利的一种作为综合分数。

对时点 t 和 t−Δ，先取两端均符合币池资格且因子值有限的共同币种集合 S。两端分别仅在 S 内排序，使用平均名次处理并列值，再归一化：

```text
q(i, t; S) = (rank(i, t; S) − 0.5) / |S|
D(t, Δ) = mean over i in S of |q(i, t; S) − q(i, t−Δ; S)|
```

D 越低，表示共同币种的相对排序越稳定。各有效时点等权汇总，避免币种较多的时段获得额外权重。该指标不使用未来收益，也不通过手续费率换算为金额。

这种定义对正比例缩放和平移不敏感，固定反转因子方向也不改变 D。它只反映排序变化，不能覆盖原始幅度变化、权重调整或组合净额交易。

### 样本与边界

- 使用精确小时网格查找 t−Δ，不以“上一条有效记录”代替，缺小时不能压缩时间。
- t 与 t−Δ 都位于当前 A 或 B 评价段内；预热只用于计算公式，不计入排名变化样本。B 起始处不足 Δ 的时段记录边界排除。
- 共同币种数量沿用合同 `min_symbols` 要求。低于要求时记录缺失原因，不填零，不插值。
- 排名变化是特征自身诊断，不因未来收益标签缺失而删除其独立诊断样本；配对优化使用下文规定的更严格共同样本。
- 保存两端合格币种数、因子有效数、共同币种数及共同覆盖比例。币种进入退出作为覆盖变化记录，不把它们自动算成排序变化。
- 对常量截面或大量并列值如实记录不同值数量与并列情况。D 为零不代表具有预测力；相关的 IC 不可估计时不能获得优化成功结论。

### 输出内容

每个 Δ 保存逐时 D、有效币种数及状态；摘要保存均值、中位数、90 分位数、有效时点数、有效时点比例，以及按现有阶段划分的均值。有效时点比例以该段应评价的完整时点网格为分母，另列边界排除和缺失数量。

报告中将 1h、4h、24h 预测证据与三个 Δ 的持续性证据并列展示。排名变化不随预测期限重复计算。首版不增加排名自相关、多个替代换手指标或复杂综合评分。

## 将证据接入 A 段优化

### 候选解释与保留

Evaluator 必须说明当前因子的预测表现、排序变化、覆盖与阶段差异。描述用“排名变化减少”或“换手倾向降低”，不写“手续费下降”“净收益改善”等尚未计算的结果。

Optimizer 在考虑修改时明确属于哪种情况：

| 比较现象 | 研究含义 |
| --- | --- |
| 预测能力保持，排名变化减少 | 有证据支持继续稳定性改进路线 |
| 预测能力提高，排名变化没有增加 | 可能同时改善两个目标，报告各自证据 |
| 预测能力与排名变化都上升 | 存在取舍，不能仅凭一个指标判优 |
| 排名很稳定但预测证据弱 | 稳定性本身不足以支持保留或继续优化 |
| 缺失增多后指标改善 | 先做共同样本比较，不将覆盖缩小解释为因子改善 |

以上是解释要求，不是额外的自动入池门槛。retain 仍需综合预测证据与研究依据；不得仅因排名变化偏高淘汰，也不得仅因排名稳定而保留。

### 新增一种受控修改实验

在现有修改实验中增加 `rank_displacement` 主指标，允许研究“在可接受的预测损失下减少排序变化”。该类型在生成修改公式之前明确：

- 原候选与修改假设，引用 A 段证据。
- 选定的预测期限 H，以及被检验的排名变化间隔 Δ，均限于 1h、4h、24h。
- 最小排名变化改善量，单位为 D 的绝对差；例如 0.02 表示减少 0.02，而非相对减少 2%。具体数值须由该路线的 A 证据支持，示例不是统一默认门槛。
- 允许的方向 IC 损失，沿用已有 `max_ic_loss` 含义。
- 必须固定的公式成分、预期结果、停止与暂停条件。

为新实验类型显式增加 H 和 Δ 字段；旧 `rank_ic` 与 `directional_spread` 合同及行为保持原样。新类型缺少必需字段应直接报错，不猜测为 24h，不填默认阈值。

不把平滑函数固定写进计算器。在正式 Agent 挖掘循环中，只有在 Optimizer 提出有证据的修改任务后，Ideator 才生成对应公式；新旧版本各自留存。后文固定研究实验可按事前登记的网格生成平滑对照，但不自动发卡或改变正式挖掘路线。这样可以实际检验平滑造成的滞后，而不是默认平滑必然有益。

### 配对比较与程序决定

降低排名变化的改善量定义为 `D_control − D_trial`，正值代表改善；预测变化为同一冻结方向下的 `IC_trial − IC_control`。

比较必须从原始因子值重算共同样本，不能直接相减两份覆盖不同的报告：每个 t 的共同集合同时满足新旧版本在 t、t−Δ 的资格和有效值要求，以及 H 期限标签有效和当前段边界要求。两版本的两端排名和 t 时点 Rank IC 都在此集合上计算，并使用共同有效时点。

独立诊断报告和配对报告各自保留覆盖数，不以配对结果覆盖原始评价。有效时点不齐时保留完整小时网格和缺失位置。

复用现有 HAC 配对不确定性计算和路线判定结构：改善与 IC 损失的区间下界同时满足预声明条件，才支持继续；任一上界仍不能满足条件则停止该路线；其余情况暂停并报告证据不足。输出仍为自适应 A 段探索证据，不新增统计显著性宣传。

本首版保持既有 HAC 参数和最低观测要求，不借此改统计合同。退化方差或无法估计区间时明确报告，不通过零值、伪置信区间或额外回退使实验判优。

停止修改路线不自动淘汰原候选。其他 H、Δ 的结果可展示，但不能在看到结果后更换本路线的目标；改目标需要新的修改实验和依据。

## 冻结与 B 段

A 段允许根据新证据提出和比较修改；送 B 前冻结公式、方向、保留期限、排名变化定义版本及 A 证据。

B 在原有一次验证中计算同定义的三个 Δ 描述性诊断，不扩大收益检验期限，不增加 BH 检验族成员，也不更改当前入池规则。诊断缺失须明确显示；B 诊断及收益结果均不回流到 A 或 Goal 任务选择。

新卡片附带排名变化摘要、覆盖及详细证据位置，使组合端后续可使用。已有卡片、旧冻结运行和历史数值不回写；旧报告缺少该指标时明确为未计算，不能显示成零或凭空补齐。

归档需区分新旧评价定义，避免在原 `factor-eval-v1` 身份下覆盖不同内容。实施前核对现有读写调用，选择最小的显式版本变更；不增加并行归档系统、历史迁移或通用兼容层。

## 实施顺序

### 第一步 确认并冻结评价定义

记录上述共同币池、排名、缺失、时间边界和配对定义；检查归档、卡片、报告及模型上下文的实际读写位置。保存一组现有评价基线，用于检查新增描述性指标不会改变旧 IC、价差和 B 判定。

### 第二步 完成确定性指标与归档

实现单候选的三个 Δ 诊断，接入新运行的 A/B 记录及报告。排名变化按候选与评价段计算一次；图表或报告可以引用，不在每个预测期限重复存储大表。

### 第三步 接通受控修改闭环

实现新实验合同、共同样本配对及现有路线状态判定，更新 Evaluator、Optimizer、Ideator 的证据要求。用确定性模型回放验证“读取证据—提出实验—生成版本—程序比较—解释去向”完整链路。

### 第四步 固定 A 段样本验证

实施时先盘点可用历史归档，冻结一个覆盖不同公式类型的有限样本清单、A 数据来源、币池、区间及计算预算，再计算诊断。样本按公式特征选择，不按 B/C 成绩挑选。

使用已有 A 因子值时保留其数据来源限制；源数据不能复现时直接报告缺口，不混用另一个数据库补齐。工程中构造的稳定排序、反转排序和缺失案例用于验证定义，不计为新研究因子。

该步骤交付固定样本分布和配对案例，观察能否识别预测能力与变化程度的取舍。真实模型调用和新增公式搜索如需开展，先明确独立的模型、样本和预算；本计划不要求恢复原 Goal 或开展无限循环挖掘。

## 验收标准

| 项目 | 必须满足的结果 |
| --- | --- |
| 指标含义 | 已知稳定排序得到零变化；明确反转排序得到可手算的正变化；常量信号不被认定为有效预测 |
| 不变性 | 正比例缩放、平移及冻结方向翻转不改变 D；时间间隔按真实小时计算 |
| 覆盖与边界 | 缺失、币种进出、并列值、段边界被明确记录，不把缺失当稳定 |
| 配对公平性 | 新旧因子均在同一币种、时点及标签集合评价，删掉难样本不能制造未披露的改善 |
| 程序决定 | 降低 D 但超出允许 IC 损失不能判优；证据不足不能自动继续；Agent 不能覆盖程序状态 |
| 研究边界 | B 结果不进入 A 优化上下文，新诊断不改变冻结收益检验范围和 BH 家族 |
| 基线保护 | 同一因子和输入下，旧 IC、价差、原实验类型与 B 准入判定保持一致 |
| 交付完整 | 新诊断可归档、读取、恢复和报告；旧数据不覆盖；未计算明确显示 |

测试集中在上述行为与已有受影响模块，使用项目要求的检查，并审阅本任务差异。测试不以自行假设的盈利、固定低换手阈值或新增卡片数量为成功条件。

工程完成意味着新证据可计算、可解释、能影响受控优化；不等于排名变化已经被证明能降低组合费用。固定 A 样本若显示改善有限或没有改善，结果应如实记录，不因此扩大搜索。

## 后续是否引入惩罚分数

首版完成后，只有在独立规划的组合开发对照中确认代理指标与实际交易损耗有用的关系，才讨论 λ、总分或硬门槛。对照需固定因子集合、数据与组合规则，并检查敞口和交易参与度，避免把少交易或长期空仓直接解释为更强预测。

单因子 D 较高的信号仍可能在组合中通过净额抵消交易，因此未来的惩罚强度也应服务于具体组合用途。相关性、组合增量和残差研究另立范围，不在本次合并实施。

## 七小时内优先开展的实验

总预算约 420 分钟，Token 不作为限制。实际约束是计算、磁盘读写、工程接入和结果复核；扩大公式搜索不能替代有区分力的对照。下列参数为拟定的固定研究网格，执行前写入实验合同，此后不按结果扩展。

### E0 指标定义与运行成本核验

问题：D 是否按定义计算，完整研究需要多少资源？

先完成稳定排序、完全反转、并列、缺小时、币种进入退出、缺失增加、正比例缩放和方向翻转的可手算案例。随后读取固定的 6 个真实 A 因子，核对归档值、时间网格、资格面板和单因子计算耗时。

产物：工程检查结果、六因子计时与内存记录、完整扫描的预计时长及最终冻结样本清单。资料缺失记录原因；不以零值、另一个来源或临时改变最少币种数补齐。

### E1 全池信号持续性画像

问题：现有候选的变化有多快，变化程度与预测表现是什么关系？

目标为 576 个历史候选的 A 值集，分别计算三个 Δ 的 D。预测侧读取可用的同源 A 多期限证据；缺少某期限证据时明确标记，不读取 B 补足。若必须重算预测评价，单独记录计算预算。

输出 D 分布、D 与方向 IC 的散点、各阶段表现、缺失覆盖、并列程度，以及公式家族汇总。H 与 Δ 分开保留，形成 3×3 对照视图，不预设只看 H=Δ。

该实验用于发现研究问题，不从全样本相关性推出因果或准入阈值。不同因子的 IC 覆盖不一致时散点属于描述性证据；正式比较仍需共同样本。若全池扫描超预算，在看结果前按公式结构分层和固定身份顺序缩小样本，并说明未完成数量。

未来参考：判断是否确有较多“预测迹象尚可但排名频繁变化”的候选，以及后续校准应分哪些期限或公式类型。

### E2 固定平滑对照与预测能力取舍

问题：减少排名变化能否保留预测信息，代价是否随预测期限变化？

事前按公式使用的字段和算子，建立仅用于抽样的分类：价格趋势与反转、波动与区间、成交与流动性、费率与基差、持仓与比例、混合结构。目标每类 4 个，共 24 个原候选；多类归属需按事先固定的优先顺序确定，类内按身份排序选取，不根据 B/C 表现选择。类别不足时保留不足，不用结果更好的类别填满。

每个原候选比较原版及三个完整历史窗口 4h、12h、24h 的因子值均值平滑版本，最多 72 个变体。使用原因子的数值序列进行时间平滑，再做截面排名和评价；方向固定，窗口仅含当前及过去观测，窗口缺值不跳过、不前向填充。预热、公式节点与最大回看预算须预检，超出约束的变体记录不适用，不能放宽原限制。

在每个父因子的所有可执行版本之间，同时给出共同有效样本结果和各自覆盖；按 H 与 Δ 展示方向 IC、价差、D 及配对差值。保留所有预定版本，不按全段最高分只报一个赢家。

此处是固定处理方法的研究对照，不是新一轮 Agent 搜索。报告预测能力与 D 的取舍图，并区分点估计较好、配对证据支持、证据不足。若未预声明最小改善与允许 IC 损失，就只报告效应及区间，不事后补阈值宣布路线成功。

未来参考：是否值得让 Optimizer 提出平滑修改、哪些窗口产生明显滞后，以及不同 H 是否需要不同的 IC 损失预算。即使全部变体都没有改善，也应形成可复用的负面结论。

### E3 A 内时间稳定性与选择偏差检查

问题：前半段看到的低变化优势，后半段是否还能出现？

复用 E1、E2 的结果，不新增变体。将 A 划为前半段 `[2022-08-01, 2023-08-01)` 与后半段 `[2023-08-01, 2024-08-01)`；跨越分界的收益标签排除，D 的两端也必须落在对应段内。

工程上隔离后半段结果：先用前半段生成取舍与候选名单并保存，再读取后半段评价这些固定选择。可保留完整网格的后半段表，但不得据此重新选择窗口。继续报告原版对照、共同覆盖和未改进比例。

划分后的样本仍来自因子发现用过的历史 A，结论称为时间迁移诊断，不能称为独立样本外证明。另以既有阶段切分查看改善是否集中在少数时间段，不增加事后挑选的行情状态标签。

未来参考：判断统一阈值是否容易失效，是否值得进一步设计滚动评价和真正的新数据检验。

### E4 原始数据与旧库插值的敏感性检查

问题：旧库事后插值是否使 D 偏低，或改变平滑后的取舍判断？

这是有条件的高优先级实验。先核实 30 币共享输入核对失败的具体范围及本实验依赖的行情、资格和标签是否可信；只做影响本实验的核查，不顺带修复另一个研究任务。若无法确认，记录阻塞并不执行本对照。

在相关输入核对通过后，选取 E2 中最多 6 个仅依赖已恢复字段的公式，保持公式、方向、币池身份、A 区间及评价规则相同，用原始重建输入重算。分别报告各来源原生覆盖，再在两来源共同样本比较 D 与 IC；不能把换币池、缺失变化和数据数值变化混成同一个效果。

未来参考：如果数据来源明显影响 D 分布，后续 λ 或阈值必须在目标数据来源上重新研究，不能直接沿用旧库统计。该实验不要求扩大下载或重建全部行情库。

## 七小时执行安排与停止条件

以下是预算分配，不是已测得的运行时间。工程与实验顺序有依赖，不能为了跑满实验而跳过正确性检查。

| 累计时间 | 主要任务 | 阶段产物 |
| --- | --- | --- |
| 0 至 30 分钟 | E0 数据盘点、定义案例和小样本资源测量 | 冻结输入、样本顺序及可完成的计算范围 |
| 30 至 150 分钟 | 指标、归档、配对合同及 Agent 证据接入 | 首版可运行链路和针对性测试 |
| 150 至 210 分钟 | E1 全池或事前缩小的固定样本画像 | 分布、覆盖和公式家族汇总 |
| 210 至 285 分钟 | E2 固定平滑网格 | 原版与变体的预测能力和 D 取舍 |
| 285 至 330 分钟 | E3 时间迁移；条件允许则安排 E4 小样本 | 稳定性结果或明确的数据阻塞 |
| 330 至 390 分钟 | 受影响模块回归、Agent 确定性回放及差异审阅 | 工程验收与研究结果独立复核 |
| 390 至 420 分钟 | 汇总结果、限制与下一步 | 可复跑产物和最终报告 |

第 150 分钟若核心正确性或接入未完成，优先完成工程，缩减 E1 样本并推迟 E2 至 E4；不能宣称全计划完成。第 330 分钟后不开始新的研究批次；用剩余时间完成当前安全检查点、验证和交付。预算内没有观察到改善时，不加窗口、不换指标、不扩大搜索来追求正结果。

Token 不设上限不代表新增无限候选；上述固定网格约束研究自由度。数值计算由确定性程序完成，模型主要用于有界的证据解释。当前 Plan 不要求多模型或多 Agent，也不指定用户未要求的模型路由。

## 留给后续的实验清单

以下项目用于未来立项，不同时加入首版产品，也不挤占首轮必需的验证时间。

| 实验 | 要回答的问题与最小对照 | 启动条件及可留下的证据 |
| --- | --- | --- |
| F1 信号滞后与预测衰减 | 将固定因子延迟 1h、4h、12h，预测同一 H 收益，与原版及平滑版对照 | E2 完成；区分平滑减少噪声与仅仅把信号推迟，所有版本共同样本 |
| F2 排名变化与幅度变化 | D 相近的因子，其标准化得分变化是否仍差异很大 | 仅作为研究指标对照，判断当前 D 是否漏掉未来连续权重组合的重要变化 |
| F3 组合净额抵消 | 固定一个基准因子集合，逐一加入固定候选，比较组合分数的变化与候选自身 D | 基准、权重和标准化先冻结；不设单因子交易，检查高 D 候选是否真的增加组合信号变化 |
| F4 与实际成交损耗对齐 | 在固定下游组合规则中，比较加入候选前后的净额换手、费用、收益与敞口 | 单独的组合实验范围；同数据同规则同预算，不将持仓规则回灌为矿工准入条件 |
| F5 惩罚系数敏感性 | 在开发子段比较少量预声明 λ 的排序及选择稳定性，再固定选择查看后续段 | F4 提供相关证据后开展；明确 IC 和 D 的缩放，保留 λ=0，不用同段收益选 λ 又证明有效 |
| F6 是否需要残差增量 | 在固定已有因子基准下，D 之外的预测增量能否改善候选选择 | 与本次成本代理分开立项，先固定基准和时间切分，防止同质化研究混入首版 |
| F7 Agent 反馈消融 | 同一候选、A 证据、模型和预算，对照有无 D 反馈时产生的修改任务 | 首版工程完成后设小规模配对实验；输出公式、实际计算表现及调用成本，不以文字评价算成功 |
| F8 新数据复验 | 冻结公式、评价定义和选择规则，观察真正后续新数据上的结果 | 需新的数据使用合同；不重命名已暴露 B/C，不自动启动 Paper 或交易 |

F7 的候选生成具有随机性，单次展示只能证明链路可用；若要声称反馈提高研究效率，需提前规定重复次数和每臂等额预算，保留所有失败版本。优先于增加模型数量的是保证两臂输入与实验预算可比。
