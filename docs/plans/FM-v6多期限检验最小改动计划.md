## 二 新准入规则

候选需要满足：A 段保留的期限与 B 段通过的期限至少有一个交集。

```text
A_retained_horizons ∩ B_passed_horizons ≠ 空集
```

例如，A 保留 1h、4h，B 通过 4h，可以入池；A 只保留 1h，B 只通过 24h，不满足同一期限的验证。

### A 段保留

A 继续使用已有的 1h、4h、24h 对照，不增加 A 段必须统计显著的门槛。Optimizer 根据完整 A 证据决定保留哪些期限，明确输出 `retained_horizons`。程序检查该集合属于 `[1, 4, 24]`、没有重复，并且每个期限都有完整的 A 数值证据；retain 必须有非空集合，其他去向不携带送检期限。

允许保留微弱但值得进一步检验的迹象。不要求 Ideator 事前准确预测最佳期限，不增加金融解释或量纲的文字准入。公式修改仍由现有修改任务与配对流程控制。

对照重放沿用原 26 个因子的候选级保留结果和原 24h 保留依据。只在隔离的 A 证据审阅中确定是否追加 1h、4h；不读取旧 B 数值、通过状态或失败理由来选择期限。新增的期限决定只生成一次，保存后两组复用，不反复调用模型寻找更有利的决定。

### 冻结与 B 段验证

冻结候选公式、固定方向、合同、A 证据及 `retained_horizons`；B 送检范围就是该冻结集合。B 读取前完成冻结，冻结后不能扩大期限范围或改变预测方向。

每个送检期限复用现有收益定义：`perp_open[t+1h+H] / perp_open[t+1h] - 1`。每小时采样一次，按该期限排除越过段边界的标签。A 的共同样本对照保留；B 报告标明各期限有效样本与边界排除数量。24h 的计算路径、样本规则和统计参数应复现旧实现。

B 对所有冻结的“候选 × 送检期限”统一进行 BH 校正。家族大小为各候选送检期限数量之和；只送检 1 个期限计 1 项，送检 3 个期限计 3 项。无法估计的检验仍计入家族，沿用现有 p=1 的校正处理。

每个期限沿用当前正式研究准入：BH 校正通过、预设方向乘平均 Rank IC 至少 0.02、有向平均价差大于零。Plan3 三轨仅作标签。首版沿用当前每小时采样、HAC 23 滞后和样本要求；不因为期限短就提高 IC 门槛，也不机械改成 0、3、23。带宽问题如需另行研究，使用独立对照，不混入本次数量验收。

BH 控制的检验对象是候选与期限的预测命题；合并成卡片后，不直接宣称卡片层面的错误发现比例也被控制在 5%。现有 B 已参与既往规则选择，本次对照属于历史研究筛选，不充当新的独立验证。

### 创意卡与 Goal 计数

一个候选只有一张卡，保存全部送检期限、通过期限、各期限统计结果、A 保留依据和 B 程序判定。机制解释必须与该候选公式、方向和期限一致；不把多期限通过拆成多张卡。

完整 B 数值检查点和模型报告齐备后才写卡。Goal 继续按实际卡片、程序准入凭据及目标匹配收据计数；只增加期限证据，不改变持续研究、等待、暂停和恢复机制。

## 四 实施与对照顺序

1. 保存当前源码状态、原 26 个因子及 7 个批次的清单，固定旧、新合同、模型设置和只读数据输入。旧结果只读，不在原运行目录补写或重算 B。
2. 在隔离快照中完成必要代码改动。先验证只送检 24h 时的计算与旧规则一致，再验证多期限链路。
3. 只用原 A 证据完成一次期限保留审阅，冻结范围；固定 24h 的原 A 保留依据，不重新生成、修复或优化公式。
4. 使用新运行目录做旧 24h 规则与新多期限规则的历史对照，保持原批次边界。两组写入隔离的卡片输出目录，分别完成报告、卡片和目标匹配；不向当前正式创意池直接混写对照结果。
5. 生成一份比较报告，逐因子列出旧、新状态、各期限证据、新增和流失原因，以及实际卡片、报告和收据位置。

不能先查看新 B 结果，再改变 A 保留期限、检验家族、HAC、IC 下限或批次划分。数值计算中断后遵守已有一次 B 访问与完整检查点恢复规则。

## 五 验证与验收

代码验证集中在现有因子挖掘、Goal、V6 合同和因子归档测试中，覆盖以下必要行为：

- 同期限 A/B 交集允许入池，交集为空拒绝入池；A 无统计显著性仍可保留送检。
- 混合送检范围的 BH 家族计数正确，缺失检验不从家族消失。
- 三个期限的下一次开盘与段边界规则正确；单独 24h 的数值结果与改动前一致。
- 冻结后修改公式、方向、期限或证据会失败；完整 B 数值检查点前不得补解释或自动重读 B。
- 多期限通过只写一张卡；重复补报告、恢复或重复成果核验不增加计数。
- 卡片、候选、归档、期限及 Goal 收据身份一致；工程检查仍不能入池，Plan3 三轨仍不成为硬门槛。

最终验收同时要求：

| 条件 | 达标要求 |
| --- | --- |
| 原规则复现 | 对固定样本复现 5 张去重合格卡 |
| 新规则实际交付 | 至少 6 张去重合格卡，均有完整报告与匹配收据 |
| 净增 | `新卡数 - 旧卡数 >= 1`，列明新增、保留和流失身份 |
| 对照可复核 | 相同因子、方向、数据和批次；完整保存每个送检期限及失败结果 |
| 工程检查 | 上述相关测试通过，并审查本任务代码 diff，移除无具体需要的防御分支 |

多期限会扩大校正家族，因此增加送检期限并不数学保证卡片增加，旧 24h 通过者也可能在新规则下失去校正支持。如果实际交付不足 6 张，本次数量目标未达标，不能以测试通过宣称完成，也不能靠放宽门槛、追加候选、重复写卡或改变家族补足数量。应报告具体损失和增益，保留现有正式执行口径，等待对研究方案的进一步决策。
